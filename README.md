# Rautahat IT Pvt. Ltd. — Digital Marketing Campaign

## Digital Marketing Portfolio Project

This project is a sample digital marketing campaign website
created by Rajan Gupta to demonstrate marketing, creative
content and IT skills.

---

## Project Purpose

The project demonstrates how an IT company can use digital
marketing to:

- Increase brand awareness
- Increase social media engagement
- Educate customers
- Generate leads
- Promote IT services
- Build a strong digital presence

---

## Services

Rautahat IT Pvt. Ltd. is presented in this project as a
sample IT company offering:

- Web Development
- Software Development
- Cyber Security
- AI & Automation
- Cloud Solutions
- IT Training
